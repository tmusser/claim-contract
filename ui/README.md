# claim-contract UI

Optional read-only React/Vite frontend for the repository claim graph.

From the repository root:

```bash
python -m pip install -e .
claim-contract ui export
cd ui
npm install
npm run dev
```

The app loads `public/claim-map.json`, generated by the Python CLI from the ledger, graph, and
optional provenance sidecar. Override the bundle URL with `VITE_CLAIM_BUNDLE_URL` when hosting
the JSON elsewhere.

Build:

```bash
npm run build
```

The UI never writes ledger or graph state. See [../docs/CLAIM_UI.md](../docs/CLAIM_UI.md) for
the provenance and privacy contract.
